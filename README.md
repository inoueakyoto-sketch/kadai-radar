# 課題レーダー v0.6.6

中学生向け・スマホ前提の課題管理Webアプリです。React + TypeScript + Viteで構成しています。

## 保存方針

データは **Firebaseや外部サーバーへ送信せず、このスマホのブラウザ内（localStorage）だけに保存**します。

保存対象：
- 課題・小テスト・ルーティン
- 完了状態
- 時間割
- 学校独自の授業名

ブラウザのサイトデータを削除した場合や、端末を変更した場合はデータが失われるため、時間割ページ下部の「データのバックアップ」からバックアップしてください。

## バックアップ

### 保存
`時間割 → データのバックアップ → バックアップを保存`

`kadai-radar-backup-YYYY-MM-DD.json` が保存されます。課題と時間割が1ファイルに入っています。

### 復元
`時間割 → データのバックアップ → バックアップから復元`

保存済みJSONを選ぶと、内容を確認後、現在の課題・時間割をバックアップ内容で上書きします。

## 主な機能
- 今日：優先課題を表示
- 全体：7日ガント + 14日間の課題集中表示
- レーダー：今日・明日・今週・来週以降を本格レーダーで可視化
- 時間割：月〜金、5〜7限。授業セルから課題登録
- 追加：授業 / 宿題・提出・小テスト / 次の授業・明日・日付だけで登録
- 毎週 / 隔週 / 毎月のルーティン
- 課題の編集・削除・完了
- PWA対応

ガントチャートと時間割の機能はv0.6.1から維持しています。


## v0.6.6 - レーダー距離ルールの明確化
- 4象限は期限のおおまかな時期（今日・期限切れ／明日／今週／来週以降）を表します。
- 中心からの距離は期限の接近度だけを表し、同じ期限の課題は必ず同じ距離に配置します。
- 点の重なり回避は角度方向だけで行い、距離にランダムなずらしを入れません。
- 同日3件以上のクラスターも同じ期限の距離を維持します。
